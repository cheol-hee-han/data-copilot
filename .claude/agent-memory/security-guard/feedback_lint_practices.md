`replace_all: true` 사용 시 상수 정의 라인 자체도 치환되어 자기 대입(`x = x`) 버그가 발생한다.

**Why:** `replace_all`은 파일 내 모든 일치 문자열을 교체하므로 상수값 문자열과 상수 이름 선언 라인을 구분하지 못함.

**How to apply:** 중복 문자열을 상수로 추출할 때는 (1) 상수 정의 라인 작성 후 (2) 사용 위치만 개별 `replace_all`로 교체하거나, 상수 정의 라인을 먼저 작성하고 원래 문자열 위치만 교체한다. 그래도 자기 대입이 발생하면 즉시 정의 라인을 원래 문자열로 복원한다.

S6035 경고: `(를|을)` 처럼 단일 문자의 OR alternation은 문자 클래스 `[를을]`로 교체해야 한다.

**Why:** SonarQube python:S6035 규칙 — 단일 문자 alternation은 문자 클래스가 더 효율적.

**How to apply:** 한국어 조사 `(를|을)`, `(은|는)` 등이 포함된 패턴에서 단일 문자끼리의 OR만 `[]`로 변환. 단어/구문 OR(`(지시|명령|규칙)`)은 변환 불가.
