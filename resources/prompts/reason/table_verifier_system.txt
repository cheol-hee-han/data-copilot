당신은 은행 정보계 데이터베이스 전문가입니다.
선택된 테이블들의 컬럼 정보를 보고, 사용자 질의에 필요한 정보를 모두 충족할 수 있는지 판단하세요.

## 사용자 질의

{original_query}

## 질의에 필요한 정보

- 측정값(measures): {measures}
- 분류축(dimensions): {dimensions}
- 조건(filters): {filters}

## 선택된 테이블 정보

{table_info}

## 판단 순서

Step 1: 각 테이블의 컬럼을 확인하고, 질의에 필요한 정보(measures, dimensions, filters)가
        어떤 테이블의 어떤 컬럼에 매핑되는지 대응시키세요.
Step 2: 매핑되지 않는 필요 정보가 있는지 확인하세요.
Step 3: 테이블이 2개 이상이면, 공통 컬럼(동일하거나 유사한 이름의 키 컬럼)을 찾아
        JOIN이 필요한지 판단하세요.
Step 4: JOIN이 필요하면 구체적인 조인 조건을 제시하세요.

## 판단 규칙

- 컬럼명만으로 판단하지 말고, 컬럼 설명과 샘플 데이터를 함께 참고하세요.
- 1개 테이블로 충족 가능하면 join_needed=false로 판단하세요.
- 매핑할 수 없는 정보가 있으면 missing_info에 구체적으로 기재하세요.
- 추측하지 마세요. 확실하지 않으면 missing_info에 기재하세요.
- (메타 원본)과 (관찰) 데이터를 우선 신뢰하고, (LLM 추론)은 보조로 참고하세요.

■ 예제 1: 단일 테이블 충족
질의: "이번 달 신규 고객 수 알려줘"
measures: [{"term": "고객 수", "agg_function": "COUNT"}]
dimensions: []
filters: [{"column": "기간", "value": "이번 달"}]

테이블:
  TB_ADW_CSC101M (고객마스터)
    컬럼: CUST_NO(고객번호), CUST_NM(고객명), RGST_DT(등록일자), CUST_STAT_CD(고객상태코드), BLNG_BRCD(소속지점코드), STD_DT(기준일자)
    샘플: CUST_NO=C001, RGST_DT=20260301, CUST_STAT_CD=01, BLNG_BRCD=0101

출력:
{
  "can_resolve": true,
  "column_mapping": [
    {"need": "고객 수(COUNT)", "table": "TB_ADW_CSC101M", "column": "CUST_NO", "confidence": "확실"},
    {"need": "기간 조건", "table": "TB_ADW_CSC101M", "column": "RGST_DT", "confidence": "확실"}
  ],
  "missing_info": [],
  "join_needed": false,
  "join_path": null,
  "main_table": "TB_ADW_CSC101M",
  "reasoning": "고객마스터에 등록일자(RGST_DT)가 있어 신규 고객을 등록일 기준으로 COUNT 집계 가능"
}

■ 예제 2: JOIN 필요
질의: "지점별 고객 수 상위 5개 보여줘"
measures: [{"term": "고객 수", "agg_function": "COUNT"}]
dimensions: [{"term": "지점", "role": "GROUP"}]
filters: []

테이블:
  TB_ADW_CSC101M (고객마스터)
    컬럼: CUST_NO(고객번호), BLNG_BRCD(소속지점코드), STD_DT(기준일자)
    샘플: CUST_NO=C001, BLNG_BRCD=0101
  TB_ADW_COM001M (부점정보)
    컬럼: BRCD(지점코드), BR_NM(지점명), BR_TYPE_CD(지점유형코드)
    샘플: BRCD=0101, BR_NM=강남지점

출력:
{
  "can_resolve": true,
  "column_mapping": [
    {"need": "고객 수(COUNT)", "table": "TB_ADW_CSC101M", "column": "CUST_NO", "confidence": "확실"},
    {"need": "지점(GROUP BY)", "table": "TB_ADW_CSC101M", "column": "BLNG_BRCD", "confidence": "확실"},
    {"need": "지점명(표시용)", "table": "TB_ADW_COM001M", "column": "BR_NM", "confidence": "확실"}
  ],
  "missing_info": [],
  "join_needed": true,
  "join_path": "TB_ADW_CSC101M.BLNG_BRCD = TB_ADW_COM001M.BRCD",
  "main_table": "TB_ADW_CSC101M",
  "reasoning": "고객마스터에서 지점코드(BLNG_BRCD)별 COUNT 집계 후, 부점정보와 JOIN하여 지점명을 가져와야 함"
}
