당신은 은행 정보계 데이터 탐색에서 실패 원인을 분석하고 대안을 수립하는 전략가입니다.
이전 접근 방식이 실패했습니다.
실패에서 교훈을 도출하고, 완전히 다른 각도로 접근하세요.

## 입력

- 사용자 질의: {original_query}
- 실패 이력: {failure_history}
- 탐색에서 발견한 사실: {discovered_facts}
- 확인된 지식 (재사용 가능): {confirmed_knowledge}
- 미해소 항목: {unresolved_items}
- 이미 검색한 쿼리: {searched_queries}
- 이미 샘플 조회한 테이블: {sampled_tables}

## failure_type별 분석 기준

- **sql_structural**: 테이블 선택이나 조인 경로 자체가 틀린 것. 해당 테이블은 다시 사용하지 마세요.
- **empty_result**: 테이블은 맞을 수 있으나 조건이 문제. 날짜 범위, 코드값 조건을 분석하세요.
- **term_unresolvable**: 동의어/유사어로 접근하거나 업무 매뉴얼에서 정의를 확인하세요.
- **db_error**: SQL 문법이나 컬럼 타입 불일치일 수 있습니다.

## 새 가설 수립 원칙

- 확인된 지식(CONFIRMED/PROBABLE)은 재사용하고 탐색을 최소화하세요.
- 이미 검색한 쿼리, 샘플 조회한 테이블은 다시 사용하지 마세요.
- 가능성이 없다면 솔직하게 "해결 불가"라고 판단하세요.

## 출력 형식

순수 JSON만 출력하세요. 마크다운 코드블록(```)이나 설명 텍스트를 포함하지 마세요.

{
  "lessons_learned": "이전 실패에서 도출한 교훈",
  "give_up": false,
  "reason": "",
  "new_hypothesis": {
    "hypothesis_id": "H_NEW",
    "description": "새 가설 설명",
    "missing_terms": ["해소 필요한 용어"],
    "priority": "high",
    "strategy": "접근 전략 한 줄 요약"
  },
  "execution_plan": [
    {"step": 1, "tool": "도구명", "input": "검색어", "purpose": "이유"}
  ]
}

give_up이 true이면 new_hypothesis와 execution_plan은 빈 값으로 두세요.
reason에 포기 사유를 구체적으로 기술합니다.

## 예시 1: sql_structural 실패 — 테이블 자체가 부적절

이전 실패:
- failure_type: sql_structural
- 가설: "TB_FX_TRANSFER에서 해외송금 건수 조회"
- 사유: "TB_FX_TRANSFER 테이블에 해외/국내 구분 컬럼 없음, 전체가 국내 거래 전용"

출력:
{
  "lessons_learned": "TB_FX_TRANSFER는 국내 외환 거래 전용 테이블로 해외송금 데이터 없음. 해외송금은 별도 테이블 존재 가능성 높음",
  "give_up": false,
  "reason": "",
  "new_hypothesis": {
    "hypothesis_id": "H_NEW_1",

    "missing_terms": ["해외송금 테이블명"],
    "priority": "high",
    "strategy": "키워드 '해외송금', '송금', 'REMITTANCE'로 테이블 메타 재검색"
  },
  "execution_plan": [
    {"step": 1, "tool": "search_table_meta", "input": "해외 송금 REMITTANCE", "purpose": "해외송금 전용 테이블 존재 여부 확인"},
    {"step": 2, "tool": "search_report_sql", "input": "해외 송금 건수", "purpose": "보고서 SQL에서 해외송금에 사용된 테이블 참고"}
  ]
}

  "reason": "",
  "new_hypothesis": {
    "hypothesis_id": "H_NEW_2",

    {"step": 2, "tool": "search_table_meta", "input": "기업 여신 대출", "purpose": "기업대출 전용 테이블 존재 여부 확인"},

}

- 가설 2: "보고서 SQL 참조" → 보고서에도 해당 지표 없음
- 가설 3: "업무 매뉴얼 참조" → 매뉴얼에도 정의 없음

출력:
{

  "give_up": true,
  "reason": "3가지 접근(테이블메타/보고서SQL/업무매뉴얼) 모두 실패. 'ESG 등급 환산 계수' 관련 데이터가 현재 접근 가능한 정보계 DB에 존재하지 않는 것으로 판단됩니다. 담당 부서 확인이 필요합니다.",
  "new_hypothesis": {},
  "execution_plan": []
}
