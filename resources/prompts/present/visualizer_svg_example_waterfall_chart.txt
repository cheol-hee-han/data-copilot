## 예제 8: waterfall_chart (폭포 차트 — 손익 분해)
────────────────────────────────

데이터:
컬럼: [항목, 금액(억원), 유형]
행: [
  ("매출액", +5000, "수입"),
  ("매출원가", -3200, "비용"),
  ("판관비", -900, "비용"),
  ("영업이익", 900, "소계"),
  ("영업외손익", -200, "비용"),
  ("당기순이익", 700, "최종")
]

계산 과정 (모델 내부 참조):
  누적 추적: 0 → 5000 → 1800 → 900 → 900(소계) → 700 → 700(최종)
  y_max = 5000 × 1.15 ≈ 5750 → 올림 → 6000
  plot: x=[90,760], y=[60,420], width=670, height=360
  scale = 360/6000 = 0.06

  막대 6개: bar_width=80, gap=33, total=6×80+5×33=645
  중앙 정렬: start_x = 90 + (670-645)/2 = 102.5
  x좌표: x1=102.5, x2=215.5, x3=328.5, x4=441.5, x5=554.5, x6=667.5
  cx (라벨 중심): 142.5, 255.5, 368.5, 481.5, 594.5, 707.5

  Y그리드 7개: 0→y=420, 1000→y=360, 2000→y=300, 3000→y=240, 4000→y=180, 5000→y=120, 6000→y=60

  막대별 위치/높이 (scale=0.06, 누적 위에서 +는 위로 쌓고, -는 아래로 깎음):
    1) 매출액 +5000  : 누적 0→5000, top=120, bottom=420, h=300, color=#1a56db (수입)
    2) 매출원가 -3200: 누적 5000→1800, top=120, bottom=312, h=192, color=#ef4444 (비용)
    3) 판관비 -900   : 누적 1800→900, top=312, bottom=366, h=54, color=#ef4444 (비용)
    4) 영업이익 =900 (소계): 0→900, top=366, bottom=420, h=54, color=#10b981 (소계)
    5) 영업외손익 -200: 누적 900→700, top=366, bottom=378, h=12, color=#ef4444 (비용)
    6) 당기순이익 =700 (최종): 0→700, top=378, bottom=420, h=42, color=#1a56db (최종)

  연결선 (점선, 막대 우측 끝 → 다음 막대 좌측 끝, 누적값 라인):
    1→2: (182.5, 120) → (215.5, 120)
    2→3: (295.5, 312) → (328.5, 312)
    3→4: (408.5, 366) → (441.5, 366)
    4→5: (521.5, 366) → (554.5, 366)
    5→6: (634.5, 378) → (667.5, 378)

  값 라벨: 양수는 막대 상단(top - 8), 음수는 부호 포함 (-3,200)
  X축 레이블: cx 위치, y=448, 4글자(매출원가) 5글자 미만이므로 회전 불필요
