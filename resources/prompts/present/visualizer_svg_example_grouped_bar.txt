## 예제 6: grouped_bar (그룹 막대 — 분기 × 채널 비교)
────────────────────────────────

데이터:
컬럼: [분기, 영업점, 인터넷뱅킹, 모바일]
행: [("1Q",320,180,250), ("2Q",340,210,290), ("3Q",360,240,330), ("4Q",380,270,380)]
(단위: 억원)

계산 과정 (모델 내부 참조):
  y_max = 380 × 1.15 ≈ 437 → 올림 → 500
  plot: x=[90,760], y=[60,420], width=670, height=360
  그룹 4개, 각 그룹 내 막대 3개:
    bar_width=35, 그룹폭=3×35=105, 그룹 간 간격=70
    total = 4×105 + 3×70 = 630
    start_x = 90 + (670-630)/2 = 110
  그룹 시작 x: g1=110, g2=285, g3=460, g4=635
  그룹 중심 cx (X축 레이블 위치): g1=162.5, g2=337.5, g3=512.5, g4=687.5

  그룹 내 막대 x: bar1=g_start, bar2=g_start+35, bar3=g_start+70
  Y그리드 6개: 0→y=420, 100→y=348, 200→y=276, 300→y=204, 400→y=132, 500→y=60

  막대 높이 = (값/500)×360, y = 420 - h
  1Q: 영업점 320 → h=230, y=190 / 인터넷 180 → h=130, y=290 / 모바일 250 → h=180, y=240
  2Q: 영업점 340 → h=245, y=175 / 인터넷 210 → h=151, y=269 / 모바일 290 → h=209, y=211
  3Q: 영업점 360 → h=259, y=161 / 인터넷 240 → h=173, y=247 / 모바일 330 → h=238, y=182
  4Q: 영업점 380 → h=274, y=146 / 인터넷 270 → h=194, y=226 / 모바일 380 → h=274, y=146

  값 라벨은 각 막대 상단(y - 8)에 표시
  범례: 3개 항목 하단 가로 정렬
