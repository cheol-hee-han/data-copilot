## 예제 10: process_diagram (선형 프로세스 다이어그램)
────────────────────────────────

데이터:
유형: 선형 5단계 프로세스
주제: 자금세탁방지(AML) 처리 절차
단계:
  1. "거래 모니터링" — 실시간 거래 감시
  2. "의심거래 식별" — 룰/AI 기반 탐지
  3. "분석 및 검토" — 컴플라이언스 심사
  4. "KoFIU 보고" — 금융정보분석원 신고 (STR)
  5. "사후 관리" — 고객 모니터링 강화

계산 과정 (모델 내부 참조):
  단계 박스: width=130, height=80, 단계 5개
  가로 배치 (좌우 여백 15씩):
    total = 5×130 + 4×30(화살표 공간) = 770
    start_x = (800 - 770) / 2 = 15
    박스 x 좌표: 15, 175, 335, 495, 655
    박스 cx 좌표: 80, 240, 400, 560, 720
    박스 y: 200~280 (수직 중앙)
  화살표: 이전 박스 우측(x=박스x+130) → 다음 박스 좌측(x=박스x+0)
    arrow1: (145, 240) → (175, 240)
    arrow2: (305, 240) → (335, 240)
    arrow3: (465, 240) → (495, 240)
    arrow4: (625, 240) → (655, 240)
  단계 번호 원: 박스 상단 중앙 (cx, 190), r=18
  설명 텍스트: 박스 하단 (cx, 320), 작은 폰트
  색상: 단계별 6색 팔레트 순환 (1차~5차)
