## 예제 9: org_chart (조직도)
────────────────────────────────

데이터:
유형: 조직도 (3계층 트리)
최상위: "행장"
2계층 (부행장 3명):
  - "영업총괄 부행장"
  - "리스크총괄 부행장"
  - "디지털총괄 부행장"
3계층 (본부 6개):
  - 영업총괄 → ["개인영업본부", "기업영업본부"]
  - 리스크총괄 → ["신용리스크본부", "시장리스크본부"]
  - 디지털총괄 → ["디지털전략본부", "IT개발본부"]

계산 과정 (모델 내부 참조):
  레벨별 Y 좌표:
    L1 (행장): y=60~110 (높이 50)
    L2 (부행장): y=180~230 (높이 50)
    L3 (본부): y=340~390 (높이 50)
  X 좌표:
    L1 행장: cx=400 (x=340, w=120)
    L2 부행장 3개 균등 분할:
      좌(영업): cx=150 (x=80, w=140)
      중(리스크): cx=400 (x=330, w=140)
      우(디지털): cx=650 (x=580, w=140)
    L3 본부 (각 부행장 아래 2개씩, w=130):
      영업: 개인영업 cx=80 (x=15), 기업영업 cx=220 (x=155)
      리스크: 신용리스크 cx=330 (x=265), 시장리스크 cx=470 (x=405)
      디지털: 디지털전략 cx=580 (x=515), IT개발 cx=720 (x=655)
  연결선: 부모 노드 하단 중앙 → 자식 노드 상단 중앙 (수직 + 수평 결합)
  부모 하단 y=110 또는 230, 자식 상단 y=180 또는 340
  L1→L2 분기: 행장 (400,110) → 중간선 (400,150) → 좌우 분기 (150,150),(400,150),(650,150) → 부행장 상단
  L2→L3 분기: 부행장 (cx,230) → 중간선 (cx,290) → 자식 (cx_child,290) → 자식 상단 (cx_child,340)
