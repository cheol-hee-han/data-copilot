## 예제 3: pie_chart (원형 차트)
────────────────────────────────

데이터:
컬럼: [카테고리, 비율]
행: [("전자제품", 35), ("식료품", 25), ("의류", 20), ("기타", 20)]

계산 과정:
  총합=100, 중심=(320,250), 반지름=150, 시작=-90°
  전자제품: -90° → -90°+126° = 36°
  식료품: 36° → 36°+90° = 126°
  의류: 126° → 126°+72° = 198°
  기타: 198° → 198°+72° = 270° (= -90° = 360°)

  arc path 공식:
    x1 = cx + r×cos(startAngle), y1 = cy + r×sin(startAngle)
    x2 = cx + r×cos(endAngle),   y2 = cy + r×sin(endAngle)
    largeArc = (angle > 180°) ? 1 : 0
    d = "M cx,cy L x1,y1 A r,r 0 largeArc,1 x2,y2 Z"
