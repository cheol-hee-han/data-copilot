## 예제 7: scatter_plot (산점도 — 두 연속형 수치 상관)
────────────────────────────────

데이터:
컬럼: [자산규모(백만원), 월거래빈도]
행: [(50,8),(80,12),(120,15),(150,18),(200,22),(250,25),(320,30),(400,35),(500,42),(620,48),(750,55),(900,62)]

계산 과정 (모델 내부 참조):
  x_max = 900 × 1.15 ≈ 1035 → 올림 → 1000 (편의상 1000으로 두되 900은 그래프 우측 근접)
  y_max = 62 × 1.15 ≈ 71 → 올림 → 80
  plot: x=[90,760], y=[60,420], width=670, height=360
  좌표 변환: px = 90 + (asset/1000)×670, py = 420 - (freq/80)×360

  X축 그리드 (0,200,400,600,800,1000): px=90,224,358,492,626,760
  Y축 그리드 (0,20,40,60,80): py=420,330,240,150,60

  점 좌표:
    (50,8)   → px=123.5, py=384
    (80,12)  → px=143.6, py=366
    (120,15) → px=170.4, py=352.5
    (150,18) → px=190.5, py=339
    (200,22) → px=224,   py=321
    (250,25) → px=257.5, py=307.5
    (320,30) → px=304.4, py=285
    (400,35) → px=358,   py=262.5
    (500,42) → px=425,   py=231
    (620,48) → px=505.4, py=204
    (750,55) → px=592.5, py=172.5
    (900,62) → px=693,   py=141

  점 표현: circle r=6, fill=#1a56db, fill-opacity=0.7, stroke=#1a56db, stroke-width=1.5
  축 레이블: X축은 그리드 아래 y=448, Y축은 좌측 x=80
