## 예제 3: pie_chart (원형 차트)
────────────────────────────────

데이터:
컬럼: [카테고리, 비율]
행: [("전자제품", 35), ("식료품", 25), ("의류", 20), ("기타", 20)]

계산 과정:
  총합=100, 중심=(320,250), 반지름=150, 시작=-90°
  좌표 공식: x = cx + r×cos(angle), y = cy + r×sin(angle)

  전자제품 35% = 126°: -90° → 36°
    start: (320, 100)
    end:   (320+150×cos36°, 250+150×sin36°) = (441.4, 338.2)
  식료품 25% = 90°: 36° → 126°
    end:   (320+150×cos126°, 250+150×sin126°) = (231.8, 371.4)
  의류 20% = 72°: 126° → 198°
    end:   (320+150×cos198°, 250+150×sin198°) = (177.3, 203.6)
  기타 20% = 72°: 198° → 270° (= -90°, 원점 복귀)
    end:   (320, 100)

  arc path 공식:
    x1 = cx + r×cos(startAngle), y1 = cy + r×sin(startAngle)
    x2 = cx + r×cos(endAngle),   y2 = cy + r×sin(endAngle)
    largeArc = (angle > 180°) ? 1 : 0
    d = "M cx,cy L x1,y1 A r,r 0 largeArc,1 x2,y2 Z"
