# 20. 고객·CIF — 고객기본 (CSC, 35테이블)

**주제코드:** CSC
**도메인약어:** CUS
**테이블 수:** 35
**최종갱신:** 2026-04-21
**주제영역 범위:** 은행과 금융거래를 맺는 모든 고객(개인·법인·단체·정부기관)의 기본정보, 연락처·주소 관리, 가족/관계자 연결, 세그먼트·VIP등급·휴면상태 관리. CSC001M CSC_고객기본은 DPG/LNB/FXC/CLN 등 거의 모든 주제영역에서 FK로 참조되는 최중요 마스터. NL-to-SQL 영업점 질의의 약 70%에서 고객 조건이 포함됨.

**[테이블 설명]**

```
[엔티티정의]
은행과 금융거래 관계를 맺고 있거나 맺은 적이 있는 모든 고객의 기본정보 마스터(CIF:Customer Information File).
개인·법인·단체·정부기관 모든 유형을 포함하며, 모든 계좌·카드·대출 등은 본 테이블의 CSN(전산고객번호)을 FK로 참조.

[대상내]
- 개인고객 (내국인, 외국인, 재외국민)
- 법인고객 (주식회사, 유한회사, 합명/합자회사, 비영리법인 등)
- 개인사업자 (사업자등록번호 기반)
- 단체 (임의단체, 종교단체, 동호회 등)
- 정부기관 (중앙·지방정부, 공공기관)
- 해지된 고객(LDGR_SCD='09') 및 휴면 고객

[대상외]
- 단순 수취인/송금인 (고객신규 미진행, 일회성 거래만 수행)
- 카드 가맹점 (SLE007M에서 별도 관리)
- 직원 (CMI007M에서 관리. 단, 본인 계좌 보유 시 별도 CSN 부여되어 본 테이블에도 존재)

[특이사항]
- CSN은 전사 유일. 합성식별을 위해 999XXXXXXX(99 prefix + 8자리) 사용
- 1 ~ 1,000,000번은 가상(합성) 고객번호이며 1,000,001번 이후가 정상고객임 
- 실명확인번호(RLNM_ALTR_NO)는 주민번호·사업자번호 대체값(A+12자리 또는 9+9자리)으로 저장
- 실제 주민번호는 저장하지 않음 (개인정보 암호화 정책)
- 개인과 법인은 CST_TCD로 구분. 개인사업자는 CST_TCD='02'이며 CSC013M에 부가정보
- 물리삭제 금지. 탈회/해지는 LDGR_SCD='09' 처리
- 고객 통합(중복 CSN 발견 시) 발생 시 UNIF_CSN 필드에 통합 대상 CSN 기록하고 본 row 는 LDGR_SCD='08' 처리
```
