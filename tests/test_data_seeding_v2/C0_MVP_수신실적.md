> **원장↔마트 관계 (NL-to-SQL 선택 지침)**
> - **원장(DPG/DPF/DPD/DPB/DPN/DPY)** = 실시간 계좌·거래 단위 데이터 (개별 계좌 잔액·금리·거래 이력)

> - "특정 계좌 정보/개별 고객 잔액" → **원장** 사용 (예: DPF001M)
> - "부점별/상품별 총 수신·신규·평잔·NPL" → **본 마트 단독** 사용 (성능 이점)
> - "이번 달 정기예금 총 잔액" 같은 일반 집계 질의는 원장보다 MVP004S 월상품수신을 우선 고려
