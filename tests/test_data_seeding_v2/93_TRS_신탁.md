```

[대상내]
- 특정금전신탁 (MMT, ELT, 채권신탁 등)

- 퇴직신탁
- 부동산담보신탁 / 부동산관리신탁 / 부동산처분신탁

[특이사항]
- 신탁재산은 고객 소유(신탁자산), 본행 자산 아님
- **쌍둥이 주의**: 동일 신탁계약이 DPN001M(수신 주제영역)에도 존재 가능.
  - TRS (투자 주제영역) = **투자관리 관점**: 위탁자-수탁자-수익자 관계·운용지시·수탁재산 관리·부동산신탁
  - DPN (수신 주제영역) = **수신원장 관점**: 잔액·이자지급·수익금 지급 등 일상 거래 처리
- "신탁 위탁자·수익자·운용지시 내역" 조회 → TRS. "신탁 잔액/이자지급" 조회 → DPN.
- 부동산신탁(담보/관리/처분)·유언신탁·가업승계신탁은 TRS 단독 관리(DPN 대상외)
- 금전신탁(특정/불특정/퇴직)은 양쪽에 중복 존재하며 동일 식별자로 연계
```
