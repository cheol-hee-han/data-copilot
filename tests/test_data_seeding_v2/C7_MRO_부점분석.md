# C7. 마트 — 부점분석 (MRO, 15테이블)

**주제코드:** MRO
**도메인약어:** MRO
**테이블 수:** 15
**최종갱신:** 2026-04-21
**주제영역 범위:** 부점(Organization Unit) 분석 마트. 인력 생산성·영업비용·수익성·상권·경쟁·효율·통폐합 후보.

> **MVB ↔ MRO 역할 분리**:
> - MVB = **현황 실적** (부점별 잔액·수익·비용·생산성 **값 자체**)
> - MRO (본 영역) = **평가·분석** (순위·목표대비·가중점수·상권·경쟁·통폐합 등 **의사결정용**)
> - MRO는 대부분 MVB에서 순위·가중치·경쟁사 데이터를 추가 가공한 결과
> - "부점별 인력 1인당 이익" → MVB007S. "부점 인력생산성 순위·Top10" → MRO001S.
> - "부점 CIR 값" → MVB006S. "부점 CIR 가중평가 점수" → MRO003S/014S.
