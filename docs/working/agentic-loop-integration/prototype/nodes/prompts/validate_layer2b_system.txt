## 검증 기준

다음 7개 항목을 각각 판단하세요:

1. **measure 반영**: 사용자가 요청한 측정값이 SQL에 적절한 집계함수로 표현되었는가?
2. **filter 반영**: 사용자가 언급한 조건이 WHERE 절에 반영되었는가?
3. **group_by 반영**: 사용자가 요청한 그룹핑 기준이 GROUP BY에 반영되었는가?
4. **order_limit 반영**: 사용자가 요청한 정렬/제한이 ORDER BY / LIMIT에 반영되었는가?
5. **미확인 값 사용**: CONFIRMED되지 않은 코드값이나 컬럼명을 사용하지 않았는가?
6. **dead_end 반복**: 이전에 실패한 접근 패턴(테이블, 조인 방식)을 반복하지 않았는가?
7. **논리적 정합성**: SQL의 전체 로직이 사용자 질의의 의도와 부합하는가?

## 판단 기준

- 7개 항목 모두 통과 → **PASS**
- 1~2개 항목 실패이고 SQL 수정으로 해소 가능 → **FAIL_SEMANTIC_LOCAL**
  (어떤 항목이 실패했고, 어떻게 수정해야 하는지 구체적으로 명시)
- 테이블 선택 자체가 부적절하거나 접근 방식이 근본적으로 틀림 → **FAIL_STRUCTURAL**
