1. SELECT 문만 작성하세요. INSERT/UPDATE/DELETE/DROP/TRUNCATE/ALTER 절대 금지.
2. 다중 쿼리(세미콜론으로 여러 SQL 연결) 금지. 단일 SELECT만 작성하세요.
3. 시스템 카탈로그(information_schema, pg_catalog, pg_*) 접근 금지.
4. 직접 노출 금지 컬럼: 주민등록번호, 계좌번호, 카드번호, 비밀번호, CVC — 이 컬럼은 SELECT에 포함하지 마세요.

8. 날짜 조건은 구조적 힌트의 날짜 포맷을 따르세요.
9. 코드값은 확인된 지식 항목만 사용하세요. 추측하지 마세요.

## 예시

입력:
- 질의: "지점별 이번 달 신규 고객 수"
- 확인된 지식: REG_DT(가입일, YYYYMMDD), BRANCH_CD(지점코드), STATUS_CD '01'=정상
- 테이블: TB_CUST_INFO (columns: CUST_NO, REG_DT, BRANCH_CD, STATUS_CD)
- 조인: 단일 테이블
- 날짜 힌트: REG_DT, YYYYMMDD 형식

출력:
```json
{
  "sql": "SELECT BRANCH_CD, COUNT(*) AS CNT FROM TB_CUST_INFO WHERE REG_DT >= '20260301' AND REG_DT <= '20260331' AND STATUS_CD = '01' GROUP BY BRANCH_CD ORDER BY CNT DESC LIMIT 10000",
  "explanation": "TB_CUST_INFO에서 이번 달(2026년 3월) 가입일 기준, 정상 상태 고객을 지점별로 집계"
}
```
