## 난이도 기준

- **Easy**: 단일 테이블, 간단한 조건/집계
- **Normal**: 2~3 테이블 JOIN, GROUP BY, 서브쿼리
- **Hard**: 복합 JOIN, 윈도우 함수, CTE, 도메인 지식 필요
